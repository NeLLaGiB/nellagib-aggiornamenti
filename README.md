# NellaGib - Launcher

Qui ci sono solo le build di **NellaGib** ("Spara come una criceta!"), scaricate dal launcher.

## Come installare
1. Scarica il launcher: **[NellaGib-Launcher.exe](https://github.com/NeLLaGiB/nellagib-aggiornamenti/releases/download/latest-57/NellaGib-Launcher.exe)**
2. Mettilo in una cartella tutta sua (per esempio `Desktop\NellaGib`) e aprilo.
3. Se Windows dice "PC protetto da Windows": **Ulteriori informazioni → Esegui comunque**
   (succede perché l'exe non è firmato con un certificato a pagamento).
4. Il launcher scarica il gioco nella cartella `gioco` accanto a sé. Poi premi **GIOCA**.

Ogni volta che lo apri controlla se c'è una versione nuova e scarica solo quello che è cambiato.
Per giocare in rete serve che tutti abbiano la stessa versione: aprite il gioco sempre dal launcher.

## Sicurezza
Il launcher installa solo aggiornamenti con la firma digitale di NellaGib e controlla l'impronta di ogni file
scaricato. Se un aggiornamento non supera il controllo non viene installato e si può giocare con la versione
che si ha già. Scarica il launcher solo dal link qui sopra.
